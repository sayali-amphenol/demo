# Amphenol Network Solutions — homepage prototype

Open `index.html` in a browser. No build step or install needed.

- `js/products.js` — product, service, market and resource data (sourced from amphenol-ns.com)
- `js/main.js` — navigation, mega menus, product finder, search, scroll reveal, hero parallax
- `assets/images/README.md` — images to export locally

## Tests

```
npm install
npx playwright install chromium
npm test
```
